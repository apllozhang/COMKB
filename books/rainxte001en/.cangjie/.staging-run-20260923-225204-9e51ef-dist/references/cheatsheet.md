# 决策规则速查 — Rainbow OXO Connect (Participant's Guide, Edition 13)

| 能力 | 一句话规则 |
|---|---|
| Rainbow 公司体系与订阅开通 | BP 建司开订阅（月付/预付）、EC 管成员分订阅；可见性默认 CLOSED，电话服务必须付费订阅 |
| OMC 安装首次连接与 IP 规划修改 | Expert 模式首连 + 证书入受信任根 + 逐客户改密；IP 四页签改完必须重启 OXO |
| OXO 接入 Rainbow 与接入排障 | PBXID+激活码填入 OMC/Cloud/Rainbow（域名保持默认），Webdiag 显示 connected with final password 即接通 |
| Rainbow 成员全生命周期管理 | 四法开户（手动/邀请/CSV/AAD）、七分区设置；删除进 10 天宽限，恢复即回落 Essential 须重配 |
| WebRTC 网关拓扑决策与容量规划 | 三拓扑按硬件与容量对号入座（集成 20/FE 20/外部 50），通道查表，150 用户上限带话务前提 |
| WebRTC 网关部署与虚拟终端配置 | Reseller 激活自动配置（边界清单）→ 三拓扑施工 → 建终端（Twinset/Anydevice 各 1 UTL）→ 行为验证 |
| Rainbow 话务台与监督组 | Attendant 订阅解锁话务台（OXO 8 路/OXE 10 路）；监督组 5 组/30 人；互助组动态进出，代接仅限同 PBX 电话呼叫 |
| Microsoft Teams 集成全流程 | 工作台级集成：Teams App 管电话面 + Rainbow Desktop 管呼叫控制；权限收敛 Telephony；在场同步须激活 O365 共享 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
