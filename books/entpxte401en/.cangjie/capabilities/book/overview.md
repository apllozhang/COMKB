## 全书主线（交付组织轴）

全书主线按章节序列展开（p41 起，p43/p44 两张架构图为底座）：

1. SSH 免密地基
2. CS 冗余（本地/空间）
3. IP 域与 CAC
4. PCS 域级生存性
5. 本地私到公溢出
6. 话机级业务集（速拨/多线监督/经理助理/寻线代接/办公桌共享/多设备）
7. Direct IP Link 组网
8. Audit/Broadcast 数据一致
9. 组网双向溢出

## 高可用三层速览（方案沟通素材）

- **中心层（CS 冗余）**：main+standby 实时 scp 复制；切换已建立通话保持；失联窗口默认 120 分钟，超时 440 只能 mastercopy（p70-79）。
- **边缘层（域+PCS）**：域按初始化 IP 归属，CAC 限跨域通话；PCS 接管断链域（四状态/回切计时器/30 天上限/单向同步）（p141-183）。
- **退路层（溢出）**：CAC 饱和/资源枯竭/断链三类触发改走公网；反方向公到私省费（p217-233, p499-536）。
