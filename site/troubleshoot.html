快速分流

  • 主备/切换/升级 → CS 冗余；域断链远端失联 → IP 域与 PCS
  • 免密/克隆连不上 → SSH 免密；命令怎么敲 → CLI 速查
  • 局间全 IP / 选项 Enabled → Direct IP Link；忙时绕公网 → 溢出重路由
  • 账单/广播不同步 → Audit 与 Broadcast；桌面/双机 → Desk sharing / Multi-device
  • 网络侧 QoS/VLAN/交换 → 网络培训门户
