安全基线与防盗打（密码体系 / Phreaking / TC1143 指针）

R — 原文依据

"The Phreaking is the name for the telephony system hacking … The victims can loose more than 20 K€ in one weekend … The freaking is a business run by organised crime"（p326-327，freaking/loose 为原文笔误，见 needs-review nr-08） "Not default • Change them regularly • Not simple, not short…"（p327） "It is mandatory to have document latest edition, read and apply its recommendations"（p329） "Total length of 8 characters • At least one lowercase alphabet letter … At least one digit (0-9) • Special characters are not allowed"（p94）

出处：OXOCXTE300EN p94-95（密码规则与历史默认密码），p325-329（安全警告讲义），p184（信箱密码）。

I — 自述

安全只有一个入口：TC1143。书内给的是常识层：

  • 密码三句常识：非默认、常改、不简单不短；安装员有责任告知用户并与客户商定安全级别
  • 管理密码硬规则：总长 8 字符、至少一个小写+一个大写+一个数字、不允许特殊字符；用户（信箱）密码 4 或 6 位数字、建议 6 位，系统拒绝 000000/123456 类弱序列
  • 七账户分层管理：管理密码集中在 OMC/Security/Passwords/Management Password，用户密码在 Subscribers Passwords；每客户密码必须不同（n03）
  • 版本陷阱：R10.1 之前的默认密码表（pbxk1064/kilo1987/help1954/tuxalize/151515）已弃用，pbxk1064 仅剩首连一个用途（n20）
  • 盗打（Phreaking）认知：目标是客户钱包——一周末可损失 2 万欧元以上，被盗线路卖长途或接高费率号，属有组织犯罪；弱信箱密码是重放主要入口（推断，n24）
  • 强制动作：获取并应用最新版 TC1143 + Expert 文档 SECURITY 章

A1 — 书中案例

安全素材（p94-95/p184/p325-329 讲义，无实验——见 needs-review nr-05）：

  1. 历史默认密码表被教材明示 "Don't use anymore"——按旧表猜密码做接管都会失败
  2. 采集表七账户逐一给定实验密码，教材同时要求每客户唯一——教学便利与安全示范自相矛盾，提取时一律标实验口径
  3. 信箱弱密码拒绝：000000/123456 配不进去；监听功能要求非默认密码
  4. 防打第一道防线：常改信箱密码+不用简单序列（p184）
  5. 升级最新版享受默认值与安全补丁（p327）

A2 — 未来触发

使用情境：交付收尾的密码清单核对；客户问"要不要改密码"；疑似盗打（话费异常/夜间国际话务）；接手存量系统改密；8328/信箱等设备默认口令清理。

语言信号：密码 / 默认密码 / pbxk1064 / 盗打 / phreaking / 话费异常 / 高费率 / 安全基线 / TC1143 / 弱密码 / 改密。

与相邻能力区分：复位对密码的影响 → 维护卡；OMC 首连改密动作 → 开通卡。本能力为策略与核查参考，不承载具体功能配置。

E — 可执行步骤

输入契约：账户台账（系统七账户+设备管理面）、客户安全级别决议。客户拒改默认口令 → 判停并书面告知风险，不默认放行。

  1. 改默认：系统七账户、8328 admin/admin、DECT PIN/AC 逐项改密。完成标准：无出厂口令残留
  2. 合规构造：管理密码按 8 位三类字符规则、用户密码 6 位数字。完成标准：密码策略核查表通过
  3. 分客户唯一：不同客户不共用密码；密码表脱敏流转。完成标准：台账无明文扩散
  4. 排查存量：接手系统按旧默认表试一次首连即改（仅验证用，不做渗透）。完成标准：存量口令更新
  5. 交付安全告知：向客户/管理员说明安全功能并商定级别（安装员责任，p327）。完成标准：告知记录签字
  6. 疑似盗打应急：改全部口令、核闭锁矩阵、查话务记录、升级按 TC1143。完成标准：损失面锁住

判停点：

  • 话费异常+夜间国际话务 → 按盗打处置，不要当普通故障排队
  • TC1143 获取不到 → 通过 BPWS/MyPortal 渠道索取，不凭记忆加固
  • 客户安全级别争议 → 书内口径只有常识三句+TC1143，超出部分明示"待确认"

输出契约：密码策略核查表（账户-规则-负责人-日期）+ 安全告知记录。

B — 边界

  • 本卡全部实验密码为教学约定值，仅作识别比对用途，严禁写进任何生产环境（n44）
  • TC1143 全文在书外——端口、防火墙、远程访问加固以其最新版为准（n43）
  • "漏配/弱口令是盗打入口"等因果判断为推断性结论，引用时保留标注（n24）
  • 网络层安全（端口/防火墙/TURN 位置）不在本书范围
