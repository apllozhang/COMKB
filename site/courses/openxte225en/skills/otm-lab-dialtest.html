R — 原文依据

"OXE CS will be DHCP server for Alcatel-lucent desk phone devices: IP addresses range: 151.1.1.151-151.1.1.159; Eco system will be DCHP server for smartphones: 151.1.1.160-151.1.1.165"（p23，DCHP 系原文拼写笔误） "Caller dials a national number 0abcd31xxx (10 digits) … called number -> 0678931001 … Caller identity received and displayed: 0298131000"（p27） "Caller dials an international number like 00ccabcd31xxx (13 digits) … called number -> 44123431001 … Caller identity received and displayed: 33298131000"（p29）

出处：OPENXTE225EN p4-30, p26-29。

I — 自述

本卡覆盖两件事：RLAB 实验环境的认知基准（仅 Boundary 背景）与拨测验证的预期结果表。

编号体系三层：

  1. DHCP：ALE 话机由 OXE CS 发池 151.1.1.151-159；智能手机由 Eco-system 发池 151.1.1.160-165（用 RAP+物理设备时，实验口径）
  2. 用户编号：存量用户 31000-31002、新建用户 31050-31052；副设备 2x31000；OTC PC 副设备 213100x；手机设备号 D 前缀、速拨号 A 前缀、Ghost Z 可 B<数字>
  3. 模拟器变换：出局拨测三种格式，末四位 31xx 即系统内分机

SIP 模拟器拨测预期表（实验口径）：

拨叫格式 位数 示例（主叫 31000） 主叫显示
国内 0abcd31xxx 10 0678931001，落分机 31001 0298131000
国内规范 33abcd31xxx 11 33123431001 33298131000
国际 00ccabcd31xxx 13 0044123431001 33298131000

实验平台认知：POD 相互独立、配置相同；每 POD 虚机池含 OTMS/OXE/OmniVista 8770/FlexLM/OMS/Eco-system/SIP 运营商模拟器等；三种学员接入拓扑（教室 RAP、RAP+话机、HTTPS 直连）。完整虚机地址与账号口令总表见 book/overview 环境区（实验口径，不进本卡正文）。

A1 — 书中案例

拨测演练（p26-29 口径）：

  1. 选格式：按目标场景定国内 10 位、规范 11 位或国际 13 位拨叫串
  2. 预判落点：末四位 31xx 对应系统内分机（31001 对应 Backman）
  3. 预判主叫显示：国内 0298131000，规范/国际 33298131000
  4. 发起呼叫并记录实际落点与主叫显示
  5. 与预期表逐格比对，偏差回到被测能力的配置链排障

A2 — 未来触发

使用情境：跟书做实验前搭对照基准；配置完成后验证呼叫行为；学员问"这个号码拨出去会变成什么"；排障时区分"配置问题"与"模拟器行为差异"。

语言信号：RLAB / POD / 实验环境 / 编号计划 / 31000 / 213100x / 模拟器 / simulator / 拨测 / 主叫显示 / caller identity / 0abcd31xxx / DHCP 池。

与相邻能力区分：被测配置本身 → PC 两模式/智能手机配置等能力；实验环境的生产化替换口径 → book/overview 环境区。

E — 可执行步骤

输入契约：被测能力（游牧/副设备/手机等）、可用分机清单、模拟器格式选择。

  1. 定预期：按格式表写出"落点分机 + 主叫显示"两个预期值。完成标准：预期值有 p26-29 依据
  2. 从被测用户发起呼叫（或向其呼入）。完成标准：呼叫建立
  3. 记录实际落点与主叫显示。完成标准：两个维度都有实测值
  4. 与预期逐格比对；一致则被测能力行为闭环。完成标准：比对记录
  5. 不一致时回被测能力排障（勿先怀疑模拟器；模拟器与真实运营商存在差异要最后排除）

判停点：

  • 实测与预期不符且配置链已核对两轮 → 停，标注"模拟器行为与真实 ITSP 存在差异"，换真实中继复测
  • 生产环境套用实验编号 → 停，编号与口令全表为实验口径，生产必须替换（n31）

输出契约：拨测比对记录（格式、落点、主叫显示）+ 被测能力的行为闭环结论。

B — 边界

  • 本卡全部数值（IP/号码/口令/域名）为 RLAB 实验口径，生产不复用；完整表见 book/overview 环境区（n31/n33）
  • 模拟器基于 OXE 实现，行为与真实运营商存在差异（p26-29 口径）
  • 原文两处拼写笔误（DCHP、inid.d 类）见 needs-review nr-01/nr-02，跟书操作时以拓扑一致性自校（n29）
  • POD 虚机清单中 DCS/OTMC 等部分虚机书中无细节，不展开
